# Security Policy

## Supported Versions

We use Docker PHP images with Alpine versions 3.20, 3.23 and 3.24

| Version | Supported          |
| ------- | ------------------ |
| 8.3     | :white_check_mark: |
| 8.4     | :white_check_mark: |
| 8.5     | :white_check_mark: |
| 8.6     | :white_check_mark: |
| < 8.3   | :x:                |

## Reporting a Vulnerability

In case you find a vulnerability that the Security Scan didn't find, please, open an issue and report it.
We will try to force the package version update that has the vulnerability
